Loomwork — UI prototypes

Static, self-contained mockups (no build step, mock data only). Open each file directly in a browser.

01 · Console

Dark three-pane console (Linear-inspired)

Projects → artifact list → detail. Shows pinning, lineage chain, per-artifact run panel with provider/model/preset/cue selectors, and a run history with statuses.

 02 · Studio

Light document-centric workspace (Notion-inspired)

Artifact-as-page: properties block (type, version, parent, provenance, tags, pinned), content body, inline run box, and a version/run history timeline.

 03 · Workbench

IDE-style testing workbench (sdd-qa loop)

Generate → run → analyze → refine stage strip, scenario spec and test-result side by side, loop log terminal, and provider/service status bar.

 04 · Workbench app — chosen direction

Interactive IDE-style app (extends 03)

Activity rail with four views: workbench loop, artifact browser with lineage navigation, cue-note library, providers & presets. Clickable stages, terminal tabs, and pin/run actions (mocked).
